# Password Policy

- **Status:** Draft
- **Last updated:** 2026-10-04

## 1. Password ที่ user ตั้งเอง [จาก flow]

| กฎ | เงื่อนไข |
|---|---|
| ความยาวขั้นต่ำ | อย่างน้อย 8 ตัวอักษร |
| ตัวพิมพ์ใหญ่ | อย่างน้อย 1 ตัว (A-Z) |
| ตัวพิมพ์เล็ก | อย่างน้อย 1 ตัว (a-z) |
| ตัวเลข | อย่างน้อย 1 ตัว (0-9) |

**[ข้อเสนอ] เพิ่มเติม**
- ความยาวสูงสุด 64 ตัวอักษร (bcrypt ใช้ได้จริงแค่ 72 bytes)
- ห้ามตรงกับ password ปัจจุบัน
- อักขระพิเศษ: อนุญาตแต่ไม่บังคับ

Regex อ้างอิง:

```regex
^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,64}$
```

## 2. Password ที่ระบบ generate [จาก flow: OTP concept]

ใช้ทั้งตอนสร้าง user และตอน forgot password

- ความยาว 12 ตัวอักษร [ข้อเสนอ]
- ต้องผ่านกฎข้อ 1 ทั้งหมด
- สุ่มด้วย cryptographically secure random (เช่น `crypto.randomInt` ใน Node.js, `secrets` ใน Python) ห้ามใช้ `Math.random()`
- ตัดตัวอักษรที่สับสนง่ายออก เช่น `0 O o 1 l I` [ข้อเสนอ]
- อายุการใช้งาน: ดู Q3

## 3. ข้อความ Error

แสดงใต้ช่อง password แบบ real-time ขณะพิมพ์ เป็น checklist ที่ติ๊กถูกเมื่อผ่าน

| กรณี | ข้อความ |
|---|---|
| สั้นเกินไป | รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร |
| ไม่มีตัวพิมพ์ใหญ่ | ต้องมีตัวพิมพ์ใหญ่ (A-Z) อย่างน้อย 1 ตัว |
| ไม่มีตัวพิมพ์เล็ก | ต้องมีตัวพิมพ์เล็ก (a-z) อย่างน้อย 1 ตัว |
| ไม่มีตัวเลข | ต้องมีตัวเลข (0-9) อย่างน้อย 1 ตัว |
| Confirm ไม่ตรง | รหัสผ่านยืนยันไม่ตรงกัน |
